# List Methods Reference

## Building and changing a list

| Code | What it does |
|---|---|
| `t = []` | Makes an empty list |
| `t.append(x)` | Adds `x` to the end of `t` |
| `t.remove(x)` | Removes the first element equal to `x` |
| `t[i] = x` | Replaces the element at index `i` with `x` |

## Reading a list

| Code | What it does |
|---|---|
| `t[i]` | The element at index `i` |
| `len(t)` | The number of elements |
| `sum(t)` | The total of a list of numbers |
| `min(t)` | The smallest element |
| `t[:]` | A copy of the whole list |



## Strings and lists

| Code | What it does |
|---|---|
| `s.split()` | Breaks a string into a list of words (the words are still strings) |
| `", ".join(t)` | Joins a list of strings with `", "` between them |
| `int(s)` | Turns a string like `"137"` into the number `137` |
| `str(n)` | Turns a number like `137` into the string `"137"` |
