Turing Machine

Tape

State 1 Step 0 Head on square 0, reading 0

Click a square to flip it between 0 and 1. Use the arrow buttons to move the head before you start. The brown frame is the head.

Rules

state reads 0 reads 1

1R2 means: write 1, move right, then go to state 2.

The machine starts in state 1. Going to state 0 means halt.

Leave a cell blank if that case should never happen. If the machine ever needs a blank cell, it stops and tells you.

Based on the Turing machine simulators by Eric Roberts and Chris Gregg (Stanford CS 208E).
